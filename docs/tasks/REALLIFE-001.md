# REALLIFE-001 — первая играбельная основа

Статус: выполнена. Локальная сборка `0.0.1` находится в `Builds/Windows/RealLife.exe`.

## Игровой результат

Запустить автономную Windows x64 игру. Персонаж от первого лица ходит по компактному двору с небольшой улицей, заходит в простой функциональный интерьер через дверь, взаимодействует с одним предметом (поднять/положить или использовать), видит состояние в базовом интерфейсе и может сохранить/загрузить свою игру. Достаточно одного помещения и небольшого правдоподобного комплекта геометрии/материалов; не строить весь город.

## Технический объём

- Создать Unity-проект URP непосредственно в корне существующего репозитория RealLife, используя результат REALLIFE-000 о найденной Unity. Проверить подходящий стабильный патч и бесплатные официальные пакеты. Зафиксировать версии. Не создавать отдельный проект или checkout.
- Создать компактный composition root, границы C#-ядра и Unity-адаптеров фактически нужных модулей, стабильные ID, базовый игровой tick/время, канонический контракт глобального положения (без полноценного GeoBake и всей планеты).
- Использовать маленькую воспроизводимую семантическую карту/район как исходный набор данных, а геометрию и взаимодействуемые объекты строить над ней. Один источник состояния двери/предмета; отсутствие прямого владения состоянием Unity-компонентами. Канонический ID и логическое положение - независимы от Transform.
- Реализовать маленький каталог, необходимый набор типизированных действий и инвентарь; сохранение/загрузка версионированной секции состояния, координат персонажа и изменения объекта. Не проектировать каталог сотен возможностей, AI, транспорт и экономику заранее.
- Первая сцена и основные Prefab через идемпотентную редакторскую автоматизацию; единая палитра, масштаб 1:1, простой свет и базовая покраска/материалы. Промежуточный dev-блокинг допустим, но итог должен быть читаемым 3D-впечатлением, а не только пустым тестовым полигоном.
- Создать минимальный локальный runner для проверок/сборки и удобный способ запуска последней рабочей Windows-сборки. Не требовать ручного редактирования сцен. Учесть отсутствие установленных инструментов честно, без имитации сборки.

## Достаточный критерий завершения

Настоящий Windows Player запускается, управляемый персонаж проходит в помещение, предмет меняет своё логическое состояние, сохранение/загрузка восстанавливает состояние; короткие автоматические проверки нужных инвариантов и запуск проходят. Никаких долгих обязательных ручных прогонов. Алгоритм сложного мира, полноценный NPC, транспорт и красивый глобус не входят в REALLIFE-001 — это следующие выпуски.

## Фактический результат

В корне создан Unity URP-проект для Windows x64 Mono. «Двор на Садовой» состоит из короткой улицы, двора и мастерской. Редактор создаёт сцену и префабы двери и фонаря из семантической карты. C#-сессия хранит устойчивые ID, позицию WGS84/ECEF, игровой тик, состояние двери и размещение фонаря. Файловый слот держит текущее и предыдущее поколения снимка версии 1.

Три проверки Edit Mode прошли. Автоматический прогон собранного Windows Player подтвердил ввод, физику закрытой и открытой двери, вход в мастерскую, перенос фонаря, запись и загрузку снимка, восстановление после повреждения текущего файла и сохранение исправного предыдущего поколения при следующей записи. Порядок запуска и управление описаны в [README](../../README.md).
